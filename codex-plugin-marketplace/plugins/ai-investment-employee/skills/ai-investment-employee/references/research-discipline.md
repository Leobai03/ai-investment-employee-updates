# 投资研究纪律

## 来源优先级

1. 监管机构、交易所、上市公司公告、定期报告；
2. 央行、统计部门、政府部门和国际组织；
3. 公司官网、管理层正式发言和投资者关系材料；
4. 有明确方法与原始数据的研究机构；
5. 新闻媒体；
6. 社交媒体和个人观点，只能作为线索，不能单独证明事实。

涉及动态信息时必须写明检索时间和数据截至时间。引用要直接指向支持该事实的页面，不能只给搜索结果页。

## 分析顺序

```text
全球局势 → 主要市场 → 重点板块 → 公司 → 对老板自选与研究假设的影响
```

只有信息能够改变老板的研究判断、风险认识或后续动作时才保留。不要堆新闻。

## 公司研究

至少检查：

- 公司靠什么赚钱；
- 行业位置与竞争优势；
- 管理层与资本配置；
- 收入、利润、现金流、负债、ROE/ROIC；
- 估值口径、日期、历史与同行对比；
- 三个支持证据和三个反方证据；
- 哪些假设成立才值得继续研究；
- 哪些信号出现需要重新评估；
- 当前缺失信息。

无法可靠核实的数字写“未核实”，不要给伪精确值。

## 影响分析

分析政策、宏观或公司事件时，写出影响链：

```text
事件 → 直接变量 → 行业传导 → 公司暴露 → 时间范围 → 反例与失效条件
```

相关性不等于因果关系。没有证据时标记为假设。

## 复盘

复盘不是判断当时“猜对没有”，而是检查：

- 当时使用了哪些事实；
- 哪些是假设；
- 哪个关键信号后来出现；
- 是否忽略反方证据；
- 下次研究流程需要修改什么。
