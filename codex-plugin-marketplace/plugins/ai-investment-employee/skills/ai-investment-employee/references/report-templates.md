# 报告模板

## 每日简报

```markdown
# 今日一句话
# 一、全球最重要的变化
# 二、对 A 股和港股的可能影响
# 三、重点板块
# 四、与自选公司的关系
# 五、反方证据与主要风险
# 六、今天只需要继续跟踪什么
# 数据缺口
# 来源与资料截至时间
```

只选最重要、最相关的 5—10 件事。

## 公司深研

```markdown
# 一句话结论
# 公司靠什么赚钱
# 行业位置与竞争优势
# 管理层与资本配置
# 财务质量
# 估值观察
# 三个支持继续研究的理由
# 三个反对理由或风险
# 假设与失效信号
# 缺失信息与下一步核验清单
# 来源与资料截至时间
```

## 临时问题

```markdown
# 重构后的研究问题
# 直接结论
# 已核实事实
# 分析与推理
# 反方证据和风险
# 还缺什么
# 下一步只研究什么
# 来源与资料截至时间
```

## 历史判断复盘

```markdown
# 当时的判断
# 当时掌握的事实
# 当时没有验证的假设
# 后来发生了什么
# 哪个判断对、哪个判断错
# 错误来自信息、方法还是纪律
# 更新后的研究假设
# 以后必须增加的检查项
```

每份报告结尾写：

> 本报告用于公开信息整理和研究辅助，不构成投资建议，也不替代持牌专业人士意见。
