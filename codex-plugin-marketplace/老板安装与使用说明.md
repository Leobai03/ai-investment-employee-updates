# AI 投研数字员工｜Codex 插件说明

## 它解决什么

普通聊天容易散。这个插件把投研流程固定下来，并把调用插件完成的 Codex 投研回合写进老板电脑上的统一档案。

完整交付包中：

```text
网页连续对话 + Codex 投研对话 + 定时汇报
                    ↓
       投研数字员工/data/research.db
                    ↓
        网页里可以搜索、筛选、回看
```

## 安装

1. Windows 双击 `安装AI投研数字员工_Windows.cmd`；Mac 双击 `安装AI投研数字员工.command`；
2. 退出并重新打开 Codex；
3. 用 Codex 打开完整产品文件夹；
4. 输入：

```text
初始化我的投研数字员工。我的重点市场是 A 股和港股，请一次只问我一个问题。
```

## 老板可以直接说

```text
把腾讯加入自选，理由是现金流、回购和 AI 业务。
```

```text
研究腾讯，并和上一次判断做对比。
```

```text
生成今天的投研晨报。
```

```text
打开定时汇报，帮我配置每小时消息面扫描。
```

## 真实边界

- 只有调用本插件完成并归档的投研回合会出现在网页“Codex”分类；
- 插件不会偷偷抓取所有普通 Codex 对话；
- 网页实时对话使用老板自己的 OpenAI API Key，不能直接借用 Codex 订阅；
- 公开网页不是 Wind、Choice 等专业终端；
- 不连接券商，不自动下单，不给个性化买卖指令。
