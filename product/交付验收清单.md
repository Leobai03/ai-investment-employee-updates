# AI 投研数字员工 v0.11.3｜Windows 首装与安全自动更新验收清单

## GitHub 自动更新

- [ ] Git 仓库不包含 `.env`、数据库、老板说明书、自选、决策、纠正、对话、报告或备份
- [ ] `vX.Y.Z` 标签只在 Windows/Linux 测试通过后创建正式 Release
- [ ] Release 同时包含无老板资料的 Windows 完整 ZIP、更新 ZIP 和各自 `.zip.sha256`
- [ ] 更新包内部每个文件均登记 SHA-256
- [ ] 更新清单尝试覆盖老板资料路径时会被拒绝
- [ ] 老板电脑默认每 6 小时检查一次正式 Release
- [ ] Codex 与网页连续对话都能识别“把投研数字员工更新到最新版”
- [ ] 网页可以查看当前版、最新版、检查时间和更新状态
- [ ] 手动安装接口要求本机确认请求头，外部网页不能简单触发
- [ ] 更新前生成一致性数据库备份和完整老板资料快照
- [ ] 新版只覆盖程序与投研插件，老板资料保持原位
- [ ] 新版健康检查失败后自动恢复旧程序和升级前数据库
- [ ] 相同版本或降级包默认被拒绝
- [ ] Windows 原生流程验证停止、备份、覆盖、依赖安装、启动和资料留存

## Windows 安装与常驻

- [ ] `Windows_首次配置.cmd` 能检查或安装 ChatGPT、Python、Node、Codex CLI、投研插件和产品依赖
- [ ] Codex 完成 ChatGPT 登录，`codex app-server --help` 可用
- [ ] `Windows_系统自检.cmd` 显示核心依赖通过
- [ ] `Windows_启动研究台.cmd` 打开 `http://127.0.0.1:8765`
- [ ] `Windows_停止研究台.cmd` 只停止本产品进程
- [ ] `Windows_查看运行日志.cmd` 能打开错误日志
- [ ] `Windows_安装开机自启.cmd` 只为当前用户创建启动项
- [ ] 后台守护发现网页异常退出后能恢复
- [ ] `Windows_卸载开机自启.cmd` 删除启动项但保留全部老板数据
- [ ] Windows 用户目录或产品目录含空格时 Codex 和网页仍可启动
- [ ] 接通电源时已按老板需要调整睡眠设置

## 双引擎

- [ ] 不配置 API Key，仅登录 Codex ChatGPT 账号也能生成报告
- [ ] 配置 API Key 后可以手动选择 OpenAI API
- [ ] 默认模式优先 Codex，Codex 不可用时回退 API
- [ ] 网页对话、每日简报、公司研究和定时任务均能选择引擎
- [ ] 消息、报告和 Markdown 归档记录实际引擎与模型

## 网页与对话

- [ ] 点击生成简报后没有全屏阻塞弹窗，可以继续切换页面
- [ ] 右上角后台任务能看到排队、运行、完成、失败和报告入口
- [ ] 网页可以新建多轮对话
- [ ] 打开任意旧对话再追问，消息继续写入原对话，不会新开窗口
- [ ] 网页发送消息后立即进入后台，发送期间仍能切换页面
- [ ] 刷新或重启后，完整对话仍存在
- [ ] 可以搜索对话标题和正文
- [ ] 可以按网页、Codex、定时任务筛选
- [ ] 实时研究正文引用可点击，消息下方有来源清单

## Codex 共用记忆

- [ ] 从网页按钮打开 Codex 时使用正确的产品工作目录
- [ ] 页面说明按钮只预填不自动发送，并解释约每 5 秒自动导入
- [ ] 产品工作目录中的 Codex 对话会自动同步到统一数据库
- [ ] 网页每次收发消息后立即写入本机对话 Markdown

- [ ] 网页“Codex”分类能看到同步回合和可点击来源
- [ ] 不读取其他工作目录和普通 Codex 对话
- [ ] 老板偏好、自选公司、报告和对话位于同一个工作区

## 长期记忆

- [ ] 完整对话全部可在网页搜索和翻看
- [ ] 老板说明书只保存明确确认的信息
- [ ] 决策、纠正和待确认推测分开保存

- [ ] 当前回答只召回相关历史，不一次载入全部档案
- [ ] 历史里的市场事实会按当前日期重新联网核验

## 公司工作区

- [ ] 公司研究提交后自动加入“我的公司”
- [ ] 添加公司的主按钮足够明显，手机和电脑上都容易点击
- [ ] 每家公司都有独立详情页，可看到基本资料、报告、对话和跟踪设置
- [ ] 公司详情页可以继续旧对话，也可以新开该公司的对话
- [ ] 公司持续跟踪支持每天、每周、每月和每年
- [ ] 自动刷新不会覆盖老板正在编辑的公司跟踪表单
- [ ] 公司研究和持续跟踪结果都关联到正确公司
- [ ] 每家公司可以新建、编辑和删除研究假设
- [ ] 假设分别记录支持、反方、验证和失效信号
- [ ] 假设状态变化后，后续研究能召回最新状态
- [ ] AI 明确把假设当作待证伪判断，而不是事实

## 来源与证据

- [ ] 港交所披露易、交易所、监管、央行和统计机构被正确标为一手来源
- [ ] 媒体转载不会因为标题含“官方”而被标为一手来源
- [ ] Reuters 等专业媒体显示为专业二手来源
- [ ] 聚合/社区来源明确提示只能作为线索
- [ ] 报告显示一手来源、正文引用和独立域名数量
- [ ] 报告统计数字事实的同行可点击引用，并展示未引用警告
- [ ] 公司档案显示对应市场的官方披露、交易所和 API 入口
- [ ] 需要密钥或数据许可的入口明确标记，不绕过认证
- [ ] 财务字段保留币种、单位、期间、合并范围、审计状态和原始文件位置
- [ ] 单一来源、无一手来源或仅检索未引用时显示证据缺口
- [ ] Markdown、Word、PDF 导出保留证据质量摘要
- [ ] 抽查引用页面，确认其直接支持紧邻事实

## 定时任务

- [ ] 可以配置每隔 N 分钟、每天、每周、每月和每年
- [ ] “哪一天”可以明确选择“每天”
- [ ] 可以从左侧新增任务，右侧暂停、恢复、试跑、编辑和删除
- [ ] 可以限制任务活跃时间
- [ ] 可以启用、停用、保存和手动试跑
- [ ] 试跑结果同时进入对话和报告
- [ ] 失败会留下状态和错误，不拖垮网页
- [ ] 每日 08:00 晨报默认启用，高频消息扫描默认关闭
- [ ] 安装开机常驻后，关闭网页仍能在后台执行
- [ ] 手动试跑不会改变下一次正式计划时间
- [ ] 同一个正式计划不会被重复执行
- [ ] 正式任务中断后，重启研究台会复用原计划记录补跑一次
- [ ] 离线期间只补最近一份，不批量回放每个错过时点

## 研究与安全

- [ ] 段永平、但斌公开方法有原始材料入口
- [ ] 框架推演明确写明不代表本人真实看法
- [ ] 不冒充投资人，不猜测本人当前持仓或即时买卖决定
- [ ] 可以生成每日简报、公司研究和临时问答
- [ ] 报告区分事实、分析、反方证据、风险和缺失信息
- [ ] 公司研究可选择事实核验员和反方研究员双复核
- [ ] 双复核最终由主研究员汇总，且没有交易角色
- [ ] 没有可靠来源时明确写未核实
- [ ] 不接证券账户、不自动下单
- [ ] 不给个性化买卖、加减仓、目标价或收益保证
- [ ] 20 组交易诱导红队样例均被输出闸门识别
- [ ] 首次违规会改写为事实、反方证据和验证信号；改写仍违规时不归档
- [ ] API Key 不返回前端、不写入数据库
- [ ] 网页只监听 `127.0.0.1`
