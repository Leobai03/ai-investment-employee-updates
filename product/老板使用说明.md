# 老板使用说明｜一页版

## 这是什么

这是您电脑上的个人投研数字员工。

您可以在网页里连续聊天，也可以在 Codex 里做研究。它会把网页对话、当前投研产品工作区里的 Codex 对话、自动汇报和正式报告整理到同一套本地档案里。

它主要研究 A 股和港股，同时观察全球市场；只做信息汇报和研究辅助，不替您买卖股票。

## Windows 第一次只做三步

1. 解压完整交付包，打开 `product`，双击 `Windows_首次配置.cmd`；
2. 按浏览器提示用老板自己的 ChatGPT 账号登录 Codex；API Key 可以不填；
3. 安装完成后网页自动打开。以后双击 `Windows_启动研究台.cmd`；希望后台自动工作时，再双击 `Windows_安装开机自启.cmd`。

第一次完成后再双击 `Windows_系统自检.cmd`。Mac 继续使用原来的 `.command` 入口。

## 默认怎么用

- `Codex 订阅优先（默认）`：推荐。先用 Codex 订阅，Codex 不可用时再用 API；
- `Codex 订阅`：不需要 API Key，但会消耗套餐内 Codex 额度；
- `OpenAI API`：需要单独的 API Key，按 API 用量计费。

每次对话、公司研究、每日简报和定时任务都能单独选择。报告里会标注最后实际用了哪个引擎。

## 网页里怎么用

1. “老板偏好”：告诉它您主要看什么；
2. “我的公司”：添加 3—10 家自选公司；点进任意公司可以看全部报告、长期对话和持续跟踪；
3. “连续对话”：像发微信一样提问；打开旧对话再追问，会继续写在原窗口里；
4. “定时汇报”：自己添加、暂停、试跑或删除消息扫描、每日晨报和基本面复盘；
5. “公开框架”：查看段永平、但斌的公开方法和原始材料入口；
6. “研究档案”：翻看所有正式报告和来源。

每家公司档案顶部会显示“这家公司会去哪里查”。A股优先巨潮和交易所，港股优先披露易，美股优先 SEC；日本、韩国的结构化接口如果需要密钥，页面会如实标明，并退回公开网页和原始文件。

公司研究有两种方式：

- “主研究员更新”：速度快、用量较少，适合日常跟踪；
- “双员工复核”：事实核验员专查数字、币种、期间和原始文件，反方研究员专找反证与失效信号，最后由主研究员汇总。它更慢，也会增加模型用量。

进入某家公司后，可以在“研究假设台账”写下目前最重要的判断。请尽量写成未来能证实或证伪的句子，并同时记录反方证据和失效信号。系统会在以后研究这家公司时召回相关假设，但不会把它当成已确认事实。

点击“生成今日简报”、发送消息或研究公司后，任务都会转到后台。页面不会被锁住，您可以继续看公司、聊天或调整任务；右上角“后台任务”会显示状态。

对话列表可以搜索公司、主题和正文，也可以只看网页、Codex 或定时任务。每条对话和每份研究报告都可以下载为 Markdown、Word 或 PDF；不需要的报告可以直接删除。

想换到 Codex 客户端时，在“连续对话”点击“在 Codex 中打开”，再发送已经填好的第一句话。研究台约每 5 秒自动导入一次当前产品工作区里的 Codex 可见对话，不需要手动同步。

这个按钮只负责打开正确的产品文件夹和预填第一句话，不会自动发送。网页和 Codex 共用本机资料与档案，但不是两个实时共屏窗口；其他 Codex 项目不会被读取。

## 它怎么记住您

- 老板明确确认的偏好，写进“老板投资说明书”；
- 老板做过的重要决定，写进“决策日志”；
- 老板指出过的误解，写进“纠正与反馈”，优先级最高；
- 网页、Codex 和定时任务的完整对话全部保存；
- 每次回答只找与当前问题相关的旧记录，不会把所有历史混在一起。

## 定时任务

关闭浏览器不会停止任务，但研究台进程必须保持运行。

安装开机自启后，登录这台 Windows 电脑会自动启动。关机、睡眠或断网期间不会执行；恢复后只补跑一份最近错过的正式计划，不会把离线期间每个时点重复跑一遍。每小时检索会消耗 Codex 订阅额度或产生 API 费用，建议先限制在 07:00—23:00。

交付时默认启用每天 08:00 的市场晨报。消息面扫描默认每 2 小时、但保持关闭；老板确认需要后再打开。左侧可以添加新任务，右侧开关负责暂停或恢复。

每家公司也可以单独开启持续跟踪，频率支持每天、每周、每月和每年。第一次建议先选“每周”，避免无意义地消耗 Codex 额度或 API 费用。

## 公开框架

系统只会根据公开材料多问几层：公司怎么赚钱、商业模式和企业文化是否改变、产业趋势是否真实、估值是否透支等。它不会冒充段永平或但斌，也不会说他们当前一定会买卖某家公司。

如果暂时不想让它自动运行，Windows 双击 `Windows_卸载开机自启.cmd`，Mac 双击 `卸载开机常驻.command`。这个动作只停掉后台服务，不会删除历史资料。

## 看结果时记住三件事

- 点击来源可以回到原网页核验；“一手来源”只表示域名已确认属于监管、交易所、法定披露、央行、统计机构或已登记公司官网；
- “待核验”只表示网站尚未登记，不等于内容一定不可靠；关键事实仍要回到原始文件；
- “数字同行引用”会提示一行数字事实旁边是否带可点击引用；这是自动筛查，仍需人工抽查原文、币种、期间和口径；
- “事实”和“分析”不是一回事；
- 系统没有证券账户权限，不自动下单，不给个性化买卖指令；
- 如果模型草稿出现买卖、加减仓、仓位、目标价或收益承诺，系统会先改写为事实、反方证据和验证信号；仍不合规就不归档。

## 隐私

对话、报告和任务配置保存在这台电脑的 `投研数字员工/` 文件夹。可选的 API Key 只保存在本机 `.env`。不要输入账号密码、验证码或不必要的私人资料。

系统只同步工作目录精确等于这个投研产品根目录的 Codex 对话，不读取其他项目、普通聊天、微信、通讯录或证券账户。

普通办公电脑就能运行，不需要独立显卡。本机只保存档案和显示网页，AI 计算由 Codex 订阅或可选 API 完成。

## 软件更新

Windows 正式版默认每 6 小时检查一次 GitHub 正式版本。更新只替换程序和投研插件，不会替换老板偏好、自选、决策、纠正、数据库、对话、报告或 `.env`。

每次安装前会自动制作数据库和完整资料快照；新版启动失败时自动恢复旧程序和升级前资料。您也可以在网页“老板偏好 → 安全自动更新”手动检查，或双击 `Windows_检查并更新.cmd`。

## 备份与换电脑

“老板偏好”页面最下面可以看到本机备份状态，也可以点“立即备份”。研究台每天自动制作数据库快照，保留最近 14 份，位置是 `投研数字员工/backups/`。

需要恢复时，Windows 必须先双击 `Windows_停止研究台.cmd`，Mac 双击 `停止研究台.command`。先另存当前 `投研数字员工/data/research.db`，再由人确认用哪份快照替换；不要在研究台运行时覆盖数据库。

换电脑时复制整个 `投研数字员工/` 文件夹。正式交付给其他人时，请运行 `生成老板交付包.command`；生成的 ZIP 会排除 API Key、真实数据库、历史对话、报告、备份和日志，并附带 `.sha256` 校验文件。
