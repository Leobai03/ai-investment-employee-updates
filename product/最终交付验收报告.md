## Windows 现场安装边界

开发机不是老板的目标 Windows 电脑，因此以下动作必须在目标电脑上由老板账号完成，不能伪装成已经代为通过：

- Microsoft Store / winget 是否被该电脑或公司策略允许；
- ChatGPT 账号的浏览器登录与套餐权限；
- Windows Defender 对正式交付 ZIP 的现场检查；
- 用户目录含空格时的实际安装、登录与 Codex 调用；
- 登录后开机自启、睡眠、断网恢复和连续两小时任务；
- 老板实际浏览器、网络代理和防火墙环境。

GitHub 工作流已经配置为在原生 Windows runner 上重复执行 PowerShell 解析和真实升级留存测试；只有远端测试通过才会发布 Release。v0.11.0 已完成公开 Release 和匿名下载校验，后续版本继续走同一套发布闸门。

交付包已提供 `Windows_系统自检.cmd` 和现场清单；在目标电脑跑通后，才完成 Windows 原生黑盒验收。

## 隔离真实模式验收

真实验收使用临时数据库，不写入老板现有档案；本机 Codex 已通过 ChatGPT 登录，实际引擎为 Codex，模型记录为 `gpt-5.6-sol`。

| 链路 | 结果 | 来源与数字审计 |
| --- | --- | --- |
| A/H 每日简报 | 成功 | 15 个来源、12 个已识别一手来源、15 个正文引用、8/8 行数字事实同行引用 |
| 腾讯公司双员工复核 | 成功 | 27 个来源、22 个已识别一手来源、19 个正文引用；系统准确提示数字引用缺口 |
| 连续对话 | 成功 | 同一对话保留 2 条消息、1 个公司一手来源、1/1 行数字事实同行引用 |

真实验收发现并修正：

1. Codex 正文链接与检索来源元数据没有自动对齐；
2. 中文文字紧邻数字时，旧规则可能漏检；
3. Markdown 表格前有总来源，但数据行本身没有同行来源；
4. 双员工深研耗时较长，现已把四段推理调为平衡档；仍应只用于重要公司深研，不作为高频默认任务。
