数据与权限边界

本机保存：对话、报告、自选公司和任务配置写入当前产品目录。

联网范围：只发送生成当前回答所需的记忆片段和公开检索请求，不发送无关本地文件。

没有交易权限：不连接券商账户，不自动下单，不输出个性化买卖指令。

✓ 偏好和报告只保存在当前电脑的产品目录。

双引擎状态

默认就是 Codex 订阅：只有订阅不可用且本机配置了 API Key 时，系统才自动切到 API。

Windows 双击 Windows_首次配置.cmd，Mac 双击 首次配置.command，即可检查 Codex 登录并可选填 API Key。Key 只写入本机 .env，不会显示在网页里。

长期记忆状态

完整消息全部留在本机；每次回答只调取老板确认的偏好、决策、纠正和与当前问题最相关的历史。这样既记得多，也不会把所有旧内容一股脑塞进回答。

Codex 同步边界：只同步在这个投研产品文件夹中创建的 Codex 对话，不读取其他项目和普通聊天。

安全自动更新

每 6 小时检查一次 GitHub 正式版本

数据保护：更新包只能覆盖程序和投研插件，不能覆盖 .env、数据库、对话、报告、老板偏好、自选公司、决策和纠正记录。安装前自动生成资料快照；新版健康检查失败会自动恢复旧程序和旧数据库。

本机备份

每天自动制作一致性快照，保留最近 14 份；只包含本产品数据库。

恢复边界：为避免覆盖正在写入的档案，恢复时必须先停止研究台，再由人确认替换数据库；产品不会静默自动恢复。
