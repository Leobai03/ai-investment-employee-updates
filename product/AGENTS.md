# AI 投研数字员工工作区

这是老板的专属投研工作区。涉及市场、公司、晨报、复盘、记忆或自选股时，优先使用已安装的 `$ai-investment-employee` Skill。

每次研究遵守：

1. 先读 `投研数字员工/00_老板投资说明书.md`、`03_研究原则.md`、`04_决策日志.md` 和 `06_老板纠正与反馈.md` 中与任务相关的内容。
2. 需要公司信息时，再读 `01_自选公司.md` 和相关旧报告；不要默认扫描全部档案。
3. 涉及当前市场、新闻、政策、财务和估值时必须联网，并优先一手来源。
4. 区分事实、分析、假设和缺失信息，同时给出反方证据与验证信号。
5. 只学习知名投资人公开讲过的方法，不冒充本人，不杜撰观点。
6. 不连接微信、通讯录、证券账户，不自动下单，不给个性化交易指令。
7. 本工作区中的 Codex 对话由网页研究台自动同步，无需重复运行手动归档脚本。
